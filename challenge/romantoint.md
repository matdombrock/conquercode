# Roman To Int

Convert the given Roman numeral string to its integer value.

Roman numerals are represented by these symbols: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. Generally, larger values come before smaller values and are added (VI = 6, MCM = 1900). When a smaller value appears before a larger value, it is subtracted (IV = 4, IX = 9, XL = 40). The input is a valid Roman numeral.

**Contibuted By:** LLM 

## Cases

III ==> 3

LVIII ==> 58

MCMXCIV ==> 1994

X ==> 10

IV ==> 4

IX ==> 9

XL ==> 40

XC ==> 90

CD ==> 400

CM ==> 900

MDCLXVI ==> 1666

MCMXC ==> 1990
